Integração pessoal — Google Agenda e Tarefas

Esta página existe por um motivo específico: o Google exige que todo cliente OAuth tenha uma página inicial e uma política de privacidade públicas antes de permitir a publicação do aplicativo. Este site é o endereço dessas duas páginas.

O que é o aplicativo

É um assistente pessoal, instalado em um único computador, que o próprio autor utiliza. Ele se conecta à conta Google do autor para ler e criar compromissos na agenda e para ler, criar e concluir tarefas. Não é um produto, não tem cadastro de usuários e não está disponível para uso de terceiros.

Escopos solicitados

  • calendar — acessar os compromissos da agenda da própria conta
  • tasks — acessar as listas e tarefas da própria conta

Nenhum outro escopo é pedido. Não há acesso a e-mail, arquivos, contatos, formulários ou qualquer outro dado.

Dados de visitantes

Esta página é estática. Não existe backend, banco de dados, cookie, script de analytics, formulário ou rastreador. O GitHub, que hospeda a página, registra requisições conforme a política dele — nada é coletado ou visto por este aplicativo.
